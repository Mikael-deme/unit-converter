# Unit Converter

A command-line application written in Python for converting values between different units of measurement.

## Features

- Convert units of length, mass, volume, area, and speed.
- Convert temperature between Celsius, Fahrenheit, and Kelvin.
- Validate user input.
- Display conversion results in the terminal.

## Technologies

- Python 3
- Standard library

## Requirements

- Python 3.12 or later

## How to Run

1. Clone the repository and select the `Final-touch` branch:

   ```bash
   git clone --branch Final-touch https://github.com/Mikael-deme/unit-converter.git
   ```

2. Enter the project directory:

   ```bash
   cd unit-converter
   ```

3. Run the program:

   ```bash
   python Unit_converter.py
   ```

## Limitations

- Only the units implemented in the program are supported.
- Invalid or unsupported conversions are rejected.
